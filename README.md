# بُعد — Bu'd Studio

الموقع التعريفي لستوديو بُعد: تطوير تطبيقات ويب وجوال، وإنتاج أفلام تسويقية بالذكاء الاصطناعي.

صفحة واحدة ثابتة، بدون أي اعتماديات بناء. عربي أساسي مع إنجليزي اختياري.

## البنية

| الملف | الوظيفة |
|---|---|
| `index.html` | الصفحة النهائية المبنية — هذا ما ينشر |
| `src/_head.html` | وسوم `<head>`: العنوان، الوصف، روابط المعاينة، الخطوط، الأيقونة |
| `src/index.html` | جسم الصفحة + التنسيقات + السكربت |
| `build.sh` | يدمج `src/_head.html` + `src/index.html` في `index.html` |

## التعديل

عدّل داخل `src/` فقط، ثم أعد البناء:

```bash
bash build.sh
```

لا تعدّل `index.html` في الجذر مباشرة — أي بناء لاحق يمسح التعديل.

## النشر

مربوط بـ Vercel. كل دفعة إلى `main` تنشر تلقائياً.

## بعد تسجيل النطاق

حدّث الروابط في `src/_head.html` من `bud.sa` إلى النطاق الفعلي:
`canonical` و `og:url` و `hreflang` و `url` في بيانات Schema.org، ثم أعد البناء.
